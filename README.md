# Lennox YT1FF (Pronto) — Home Assistant integration

Control a **Lennox ductless heat pump** that comes with the **YT1FF** infrared remote (Gree family) from Home Assistant.
The integration *computes* the infrared code from the settings you choose (mode, temperature, fan, louver…) and sends it through
an infrared emitter of Home Assistant's `infrared` platform, for example the **SofaBaton X1S** hub with the *SofaBaton X* integration.

## Tested hardware

| | |
|---|---|
| Heat pump | Lennox **MS8-HI-18P1A** |
| Remote | **YT1FF** (all codes were reverse-engineered from this remote) |
| Emitter | SofaBaton **X1S** hub (*SofaBaton X* integration) |

Other Gree-family units or emitters *may* work but are **untested**. Any emitter entity of the `infrared` platform should do, but only
the SofaBaton X has been tried. Home Assistant must be recent enough to provide the `infrared` platform.

## Features

* `climate` entity: off / auto / cool / dry / fan only / heat, 16–30 °C, fan auto/low/medium/high, 10 louver positions.
* Switches: display light, *health*, *X-Fan*, *turbo*, **I feel**. Select: displayed temperature (inside / outside / target / off).
* **Per-mode memory** of target temperature, fan speed, X-Fan and louver, restored when you come back to a mode (kept across restarts).
* **Mode rules of the real remote**: auto → fixed 23 °C, no X-Fan, no turbo · dry → fan low, no turbo · fan only → no X-Fan, no turbo ·
  heat → no X-Fan. Controls that a mode forces become unavailable.
* **I feel**: sends the temperature of a Home Assistant sensor to the unit (on every command and every N minutes, 5 by default), so the
  unit regulates on the sensor you chose instead of its own. Verified on the unit (the sent values are displayed as-is).
* Services: `generate_pronto` (compute a Pronto code without sending), `decode_pronto` (decode a code from the real remote and tell
  whether the generator reproduces it), `send_pronto` (send a raw Pronto code, for diagnostics).
* The state is *assumed* (infrared is one-way) and restored after a restart.

## Installation

**With HACS (custom repository)**
1. HACS → ⋮ → *Custom repositories* → add `https://github.com/nicolas-com/ha-lennox-yt1ff`, category *Integration*.
2. Install *Lennox YT1FF (Pronto)* and restart Home Assistant.

**Manually**: copy `custom_components/lennox_yt1ff/` into `/config/custom_components/` and restart.

Then *Settings → Devices & services → Add integration → Lennox YT1FF (Pronto)*, choose the infrared emitter entity and, optionally,
a room temperature sensor (**required for I feel**). The options let you change the sensor and the I feel interval.

## Known limitations

* **The unit's own timers are not exposed.** Frames carrying timers (decoded and regenerated byte-for-byte from the real remote) were
  accepted by the unit but not executed when sent from Home Assistant; the cause was not found. Use Home Assistant automations instead.
* Not exposed: *sleep*, Wi-Fi flag, horizontal swing and Fahrenheit (not seen on this remote).
* Because infrared is one-way, using the physical remote makes the state shown in Home Assistant diverge.
* Verified only on the hardware above.

## Technical documentation

The protocol (bytes, checksums, timers, I feel) is documented in [docs/PROTOCOL.md](docs/PROTOCOL.md). `python tests/test_protocol.py`
decodes the 61 recorded Pronto captures in `tests/` and checks that the encoder reproduces each one byte-for-byte.
`python tools/analyze_pronto.py file.txt` decodes your own captures.

References consulted: the public Home Assistant developer documentation for the `infrared` platform and the public documentation of the
Gree protocol in the IRremoteESP8266 project (nothing was copied from it).

# Français

Intégration Home Assistant pour une **thermopompe murale Lennox** livrée avec la télécommande infrarouge **YT1FF** (famille Gree).
Elle **calcule** le code infrarouge à partir des réglages (mode, température, ventilation, volet…) et l'envoie par un émetteur de la
plateforme `infrared` de Home Assistant, par exemple le hub **SofaBaton X1S** avec l'intégration *SofaBaton X*.

> **Avertissement.** Projet communautaire indépendant, **non affilié** à Lennox, Gree, SofaBaton ou Home Assistant (marques citées
> uniquement pour indiquer la compatibilité). Logiciel fourni **« tel quel », sans aucune garantie** ([LICENSE](LICENSE)). Il commande un
> appareil de chauffage/climatisation : utilisation à vos risques.

**Matériel testé** : thermopompe Lennox **MS8-HI-18P1A**, télécommande **YT1FF**, hub SofaBaton **X1S**. Le reste est **non testé**.

**Fonctions** : entité `climate` (arrêt/auto/froid/déshumid./ventilo/chaud, 16–30 °C, ventilation, 10 positions de volet) ; interrupteurs
voyant, health, X-Fan, turbo, **I feel** ; affichage de température (intérieure/extérieure/consigne/éteinte) ; **mémoire par mode**
(consigne, ventilation, X-Fan, volet) ; **règles de la vraie télécommande** par mode (auto fixe à 23 °C, X-Fan et turbo imposés selon le mode) ;
**I feel** avec le capteur de température de votre choix ; services `generate_pronto`, `decode_pronto`, `send_pronto`.

**Installation (HACS)** : HACS → ⋮ → *Dépôts personnalisés* → ajouter l'adresse du dépôt (catégorie *Intégration*), installer, redémarrer,
puis *Paramètres → Appareils et services → Ajouter une intégration*.

**Limites** : les minuteries de l'unité ne sont pas exposées (acceptées par l'unité mais non exécutées lorsqu'elles sont envoyées depuis
Home Assistant, cause inconnue : utilisez des automatisations) ; l'état est supposé (infrarouge à sens unique) ; seulement vérifié sur le
matériel ci-dessus.
